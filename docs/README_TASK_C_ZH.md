# Task C · 分组共形预测

[English version](README_TASK_C.md)

Task C 使用 Pl@ntNet-Trunc 的预计算分类概率，比较频率分组和混淆分组。两种方法都让同组物种共用一条候选入选门槛，并采用相同的校准和评估规则。

## 数据划分

每次从原校准池抽取 10%、30% 或 100% 的数据作为本轮标签预算，每档使用种子 0–9。配对实验调用 Task B 的 `get_split`，把选中的样本分成 20% 的设计集和 80% 的校准集。

- **设计集**用于统计各物种的样本数，并为混淆分组估计模型的混淆模式。设计样本少于 3 条的物种进入备用组，两种配对方法共用这批备用类。
- **校准集**用于估计各组的阈值。开始校准前已确定物种所属的组。
- **测试集**用于生成预测集并评估覆盖率与集合大小。测试标签只用于最终评分。

## 分组方法

- **频率分组（方案 A）**。按训练照片数从少到多排列非备用类，依次切成 5 组，每组的物种数最多相差 1。训练频数相同的物种按类别 ID 排序。如果混淆法的有效常规组少于 5 个，配对频率法使用相同的组数。
- **混淆分组**。对设计集中真实类别相同的照片，先取模型预测概率的平均向量，再把真类分量置零，并用其余分量的和做归一化。这样可以比较模型容易把各物种认成哪些其他物种。将这些向量用 K-means 分成 5 个常规组，随机状态沿用切分种子，初始化次数为 10。非真类概率之和为零时保留零向量。若不同向量少于 5 个，组数降为不同向量的数量。所有物种都缺少足够的设计样本时，只保留备用组。
- **满预算频率分组**。按训练频数对全部物种排序并均分成 5 组，再用 `get_full_calibration_split` 取得本轮预算内的全部样本用于校准。这个版本同时改变了分组和校准样本量。

## 阈值和预测集

设 $p(y\mid x)$ 为模型对照片 $x$ 属于物种 $y$ 的预测概率，分数定义为 $s(x,y)=1-p(y\mid x)$。校准时，每张照片贡献一个真类分数，放到真类所属的组里。

若组 $g$ 有 $n_g$ 条校准样本，目标覆盖率 90% 对应的排序位置为

$$
k_g = \lceil 0.9(n_g + 1) \rceil.
$$

当 $k_g \le n_g$ 时，阈值 $q_g$ 是该组从小到大数第 $k_g$ 个分数。否则取 $q_g=+\infty$。因此，0 条或 8 条样本时阈值为无穷大，9 条时取最大的校准分数。备用组也用这条规则。

对于新照片，每个候选物种用它自己所在组的阈值判断。分数等于阈值时也会入选。

$$
C(x) = \{y : 1-p(y\mid x) \le q_{g(y)}\}.
$$

无穷大阈值对应的物种必定出现在每个预测集里，它们的数量就是集合大小的下界。分组确定后，在组内校准样本与测试样本可交换的条件下，覆盖率保证适用于整个组。单个物种的覆盖率由测试集估计。

## 运行和验证

先准备预计算数据，再在项目根目录运行以下命令。 [项目安装说明](../README.md#setup)

```sh
uv sync --locked
uv run --locked python -m unittest discover -s tests -p test_grouped.py
uv run --locked python -m scripts.analyze_grouped_coverage
```

## 指标和交接文件

总体覆盖率和平均候选数按训练频数加权。稀有类覆盖率对训练频数最低三分之一的类别等权平均，常见类覆盖率对最高三分之一的类别等权平均。宏平均覆盖率对全部类别等权平均。覆盖率差为常见类覆盖率减去稀有类覆盖率。

- 逐次实验结果有 90 行，按 `method`、`protocol`、`budget` 和 `seed` 区分。配对比较使用 `standard_80` 下的 `frequency` 和 `confusion` 两种方法。满预算频率分组记为 `frequency / full_100`。 [逐次结果 CSV](../results/grouped_coverage_all_runs.csv)
- 跨种子汇总有 9 行。每个指标的 `_mean` 和 `_std` 分别表示 10 个种子的均值和样本标准差。所有运行共用一份测试集，因此这里的标准差反映设计和校准划分变化带来的波动。 [汇总 CSV](../results/grouped_coverage_summary.csv)
- `fallback_n_classes` 是备用类数量，`fallback_class_fraction` 是备用类占全部类别的比例，`min_set_size` 是阈值为无穷大的类别数。
